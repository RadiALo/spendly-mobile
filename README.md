# 📱 **Spendly**

**Your simple companion to control spending and save more - especially
when life gets chaotic.**

After relocating, I realized how hard it became to keep track of my
daily expenses. Spendly was created to solve exactly this problem:\
**a minimal, stress-free app to help you stay within your budget.**

------------------------------------------------------------------------

## 🚀 **How It Works**

1.  **Set your spending goal** - daily, weekly, monthly, or yearly.
2.  **Log your expenses with one tap.**
3.  **Track how much you've spent and how much you can still spend.**

That's it - simple and effective.

------------------------------------------------------------------------

## 🛠️ **Tech Stack**

Built with **React Native** + **Expo**

------------------------------------------------------------------------

## ✨ **Features**

-   Set **Daily / Weekly / Monthly / Yearly** spending limits
-   Quickly report any spending
-   Track how much money you've saved over time
-   Clean and minimal interface
